# Тестовое приложение VPN

## Для того, кто раздаёт

1. Соберите APK одной командой из корня репозитория:

   ```
   scripts/share-apk.sh
   ```

   Скрипт запускает сборку в GitHub Actions (15–20 минут), кладёт файл в `~/vpnclient-apk/` и сразу удаляет его копию с GitHub: репозиторий публичный, а в сборке зашит адрес тестового сервера.
2. Отправьте APK другу в личный чат вместе с текстом ниже. В открытые чаты и каналы файл не выкладывайте.

Каждая сборка подписана своим тестовым ключом. Новую сборку поверх старой Android не поставит: старую нужно удалить и войти заново.

## Для друзей: как подключиться

Тестовая версия, только для Android. Доступ бесплатный на 3 дня, сервер в Стокгольме.

### 1. Ник в Telegram

Приложение находит вас по нику в Telegram. Если ника нет, задайте его: Telegram → Настройки → Имя пользователя.

### 2. Бот

Откройте бота [@testVpn_project_bot](https://t.me/testVpn_project_bot) и нажмите «Start». Бот ответит, что можно вводить ник в приложении.

### 3. Установка

1. Откройте присланный файл `.apk`.
2. Телефон спросит, разрешить ли установку из этого источника (Telegram или «Файлы»). Разрешите.
3. Если Play Protect предупредит о неизвестном приложении, нажмите «Всё равно установить»: тестовая сборка не из Google Play.

### 4. Вход

1. Откройте приложение и введите свой ник.
2. Бот пришлёт 6-значный код. Введите его в приложении.

### 5. Подключение

1. Выберите сервер «Stockholm» и нажмите большую круглую кнопку.
2. При первом подключении Android спросит, разрешить ли VPN. Разрешите.
3. Статус «Подключено» — можно пользоваться.

### Если что-то не так

- **Не смахивайте приложение из списка недавних.** На некоторых телефонах, например Samsung, это выключает VPN. Сворачивайте кнопкой «Домой».
- **Сайты не открываются, хотя написано «Подключено».** Отключитесь и подключитесь снова, попробуйте второй сервер Stockholm. Не помогло — напишите тому, кто прислал приложение: модель телефона, версию Android, время и что именно не открылось.
- **Бот не присылает код.** Проверьте, что нажали «Start» в боте и ввели в приложении тот же ник, что в Telegram.
- **Прошло 3 дня, и всё перестало работать.** Тестовый доступ закончился, напишите тому, кто прислал приложение.
